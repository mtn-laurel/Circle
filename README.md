#What Our Application Does

Social media applications can be difficult to navigate for older adults. By creating a social media application designed to accomodate older adults, we hope to increase engagement that provides meaningful social interactions and can improve users' quality of life.


#Running the React Application

To run this program you must install node version 20+ and install vite onto your desktop using the github repositories below.

To get access to the react website go into the project directory in your terminal and run the command: npm run dev. This gives you a link to the local host website which will take you to the prototype.


# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)


## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
